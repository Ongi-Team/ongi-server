  type: feedback
---

파일을 작성하거나 수정하거나 생성하는 작업은 사용자가 명시적으로 요청할 때만 수행한다.

**Why:** 사용자가 먼저 분석/설명/제안을 보고 싶어하지, 바로 파일을 건드리는 것을 원하지 않음. 2025-05-29에 직접 지적받음.

**How to apply:** 코드 분석, 오류 원인 파악, 개선 방향 제안은 자유롭게 하되, 실제 Edit/Write/Bash(git) 등으로 파일을 변경하는 행동은 "수정해줘", "추가해줘", "적용해줘" 등 명확한 요청이 있을 때만 실행한다.
